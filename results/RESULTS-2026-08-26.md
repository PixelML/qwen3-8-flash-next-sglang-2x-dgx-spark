# Results — 2026-08-26

## Test system

- Two NVIDIA DGX Spark systems, one GB10 GPU per node.
- Direct RoCE connection between nodes.
- Tensor parallel size 2.
- `RadixArk/Qwen3.8-Flash-Next-NVFP4` at revision
  `7b719225242aacd3dbd3f9407468c2ee9a9d2594`.
- `lmsysorg/sglang` image digest
  `sha256:12d3392bdc8be8d35e9a95f191df6aef99c5114bdbefd41bfdc7e760e6d25ec1`.
- 262,144-token context and 36 maximum running requests.
- NEXTN/MTP speculative decoding disabled for this baseline.

## Functional validation

The OpenAI-compatible endpoint passed:

- Text/code generation.
- `reasoning_content` at low, medium, and xhigh effort.
- Structured tool-call parsing.
- Image input and visual question answering.
- Authenticated proxy invocation using the public model alias.

Both rank containers remained healthy with zero restarts after the tests.

## Clean baseline

The benchmark submitted identical 192-token coding requests directly to rank
zero. Aggregate output throughput counts completion tokens returned by the API
and divides by wall-clock time.

| Concurrency | Completion tokens | Wall seconds | Aggregate output tok/s |
| ---: | ---: | ---: | ---: |
| 1 | — | — | 26.09 |
| 4 | 759 | 8.440 | 89.93 |

The authenticated public TLS/proxy path measured 21.77 output tok/s for a
single request. That number includes proxy, TLS, and network latency and should
not be interpreted as total server capacity.

## Interpretation

The model has 176B total parameters and 6B active parameters per token. Active
parameters are a compute estimate, not a latency guarantee. Single-stream
decode also pays for recurrent/QSA kernels, expert routing, weight movement,
and cross-node synchronization at every tensor-parallel layer.

The official low-latency profile enables NEXTN/MTP speculative decoding. This
baseline leaves it off because the deployment first prioritized correctness on
GB10/SM121. An MTP result should be reported separately after its kernels,
memory use, acceptance rate, and output quality pass a controlled soak test.
